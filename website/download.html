curl -fsSL https://taskmaster.mdnlabs.dev/install.sh | bash

Follow on GitHub

Build from source

You need Rust 1.85 or newer.

git clone https://github.com/MarshallNickolauson/TaskMaster.git
cd TaskMaster
cargo run --release

Some processes belong to other users; ending those needs TaskMaster to run with matching privileges.
